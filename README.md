## Project Overview

Whisper is designed as a modern, immersive web experience built with semantic HTML5 and custom modular CSS. The site balances sleek dark-mode aesthetics, high-fashion editorial layouts, and intuitive user navigation to present a curated lineup of luxury products, cocktail-inspired shade collections, exclusive brand stories, and upcoming events.

---

## Features & Page Structure

* **Home (`index.html`)**  
  An immersive entryway introducing the brand narrative, featuring high-resolution hero visual assets and a sleek dark aesthetic.

* **About Us (`about.html`)**  
  An editorial, wide-format layout utilizing alternating zig-zag text and media blocks to detail the story, vision, and inspiration behind the brand.

* **The Menu (`menu.html`)**  
  An interactive showcase presenting product ranges across distinct categories, including the Cocktail Line, Shots Line, and After Hours collection.

* **Events (`events.html`)**  
  A dedicated platform for exclusive brand launches, pop-up showcases, and RSVP interactions.

* **Contact Us (`contact.html`)**  
  A clean interface for customer inquiries, press contacts, and location details.

* **Shopping Bag / Cart (`cart.html`)**  
  A standalone cart interface featuring custom minimalist vector iconography, enabling customers to review selected items, manage quantities, and transition seamlessly to checkout.

---

## Technical Highlights & Design System

* **Semantic HTML5:** Clean, accessible markup optimized across all site pages.
* **Custom Responsive CSS (`styles.css`):** Built-in dark mode color palettes, flexbox header navigation, CSS grid systems, and custom hover states.
* **Header & Brand Identity:** Custom luxury header integrating the official sparkling **Whisper** logo and an inline vector SVG tote bag icon with an active item counter badge.
* **Responsive Layouts:** Media queries ensuring smooth adaptations across screen widths, from desktop luxury displays to mobile screens.
* **Maintainable Code Architecture:** Extensively documented codebase featuring inline visual and structural comments to simplify long-term project maintenance and component handoffs.
